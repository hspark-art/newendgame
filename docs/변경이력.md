# 변경 이력

업데이트할 때는 해당 버전의 **올릴 파일**만 FTP로 덮어쓰면 됩니다. (`app/config.php` 는 절대 덮어쓰지 않습니다)
경로는 `www` 폴더 기준입니다.

---

## v1.3.0 (2026-10-01) — 기존 끝장전 상품·지급 기능 반영

**배포 파일:** PC 버전 `endgame-desktop-v1.3.0.zip` (새 폴더에 풀고 기존 `data` 폴더를 옮겨오기) / 웹 `endgame-web-v1.3.0.zip`

**웹 버전에 올릴 파일** (v1.2.0 에서 업데이트하는 경우):
- 새 파일: `cumulative.php`, `items.php`, `prize_import.php`, `prize_photo.php`, `settings.php`
- 새 파일: `api/note.php`, `api/prize_field.php`, `api/prize_quick.php`, `api/winners.php`, `app/note.php`, `assets/prizes.js`
- 바뀐 파일: `activity.php`, `broadcast.php`, `collector.php`, `donations.php`, `export.php`, `index.php`, `prize_edit.php`, `prizes.php`, `viewer.php`
- 바뀐 파일: `app/bootstrap.php`, `app/helpers.php`, `app/layout.php`, `app/migrate.php`, `app/prizes.php`, `app/stats.php`
- 바뀐 파일: `assets/app.css`, `assets/collector.js`
- 상품 사진은 `app/storage/uploads/` 에 저장됩니다. 이 폴더는 지우거나 덮어쓰지 마세요.

**DB 변경:** 있음 (구조 버전 2). 파일을 올린 뒤 처음 접속할 때 자동으로 적용됩니다. 기존 자료는 그대로 유지됩니다.
- 새 표: `prize_items` (상품 목록), `broadcast_users` (회차별 시청자 요약, 누적 순위용)
- `prizes` 에 칸 추가: `item_id`, `note_sent_at`, `note_result`, `ext_id`
- `broadcasts` 에 칸 추가: `users_sig`, `users_at`

**변경 내용:**
- **상품 목록 (새 메뉴):**
  - 상품별 사진·아이콘·색·쪽지 문안 종류를 등록하고, ▲▼ 로 순서를 정합니다.
  - 아이콘·색·문안 종류는 이름으로 자동으로 정합니다. (기존 관제 화면 규칙: 마우스 🖱️, 유니폼 👕, 안경 👓, 쿠폰·코드 🎟️ …)
  - 당첨 등록 때 상품을 목록에서 고릅니다. 목록에 없으면 직접 입력할 수 있습니다.
- **당첨 표시:**
  - 수집 창 채팅, 후원 순위, 채팅 활동량, 시청자 상세, 누적 순위의 닉네임 옆에 "당첨 N" 과 받은 상품 아이콘을 표시합니다.
- **수집 창 채팅 클릭 지명:**
  - 채팅 줄을 누르면 오른쪽 [당첨 지명]에 그 시청자의 당첨 이력과 경고가 나옵니다.
  - 경고: 같은 상품 🚫, 최근 3개월 당첨, 누적 당첨
  - 상품을 고르고 [당첨 등록]을 누르면 바로 등록되고 회차에 자동 연결됩니다.
  - 닉네임 옆 ✉ 를 누르면 아이디를 복사하고 쪽지 창(또는 방송국 페이지)을 엽니다.
- **상품 지급 화면 보강:**
  - 🚨 같은 상품 중복 당첨 배너
  - 최근 당첨자 (1·2·3개월, 2회 이상은 빨간색)
  - 상품별 개수 칩 (누르면 그 상품만 보기)
  - 쪽지 보냄·안 보냄 필터
  - 표에서 바로 고치기: 아이디·닉네임·사유·상태·메모 (칸을 벗어나거나 Enter 로 저장)
  - [표 복사]: 엑셀·구글 시트에 붙여넣기용이며, 수령자 개인정보는 빠집니다.
  - CSV 에 쪽지 칸이 추가되고, 화면 필터를 그대로 따릅니다.
- **쪽지 바** (당첨자를 체크하면 화면 아래에 나타남):
  - 상품의 쪽지 문안 종류에 맞춰 문안을 자동으로 고릅니다. (기존 당첨자 시트 문안 그대로)
  - [받는사람 복사], [내용 복사], [쪽지 쓰기창 열기], [✅ 보냄 처리]
  - 관리자는 [🚀 서버로 바로 보내기]도 쓸 수 있습니다.
    - 한 명씩 0.9초 간격으로 보내고, 결과(성공, 수신 거부, 세션 만료)를 기록합니다.
    - 세션이 만료되면 그 자리에서 멈춥니다.
- **설정 (새 메뉴, 관리자):**
  - 쪽지 링크와 쪽지 쓰기창 주소
  - 쪽지 문안 4종 편집·기본값 되돌리기
  - SOOP 쪽지 서버 발송용 회사 계정 로그인 세션 등록(암호화 저장), 확인, 삭제
- **누적 순위 (새 메뉴):**
  - 2·4·8·12·26주를 고르고, 🔥 연속 출석·참여 회차·기간 채팅·기간 별풍선·기간 애드벌룬 순으로 볼 수 있습니다. (기존 누적 순위와 같은 기준)
  - 제외 명단·방송인·매니저는 빠지고, CSV 로 내려받을 수 있습니다.
  - 회차 요약을 따로 저장해 두므로, [채팅 기록 삭제]로 용량을 정리한 회차도 누적 순위에는 남습니다.
- **기존 당첨 기록 가져오기 (관리자):**
  - 기존 시스템의 `winners.json` 이나 당첨자 시트 CSV 를 올리면, 미리 보기를 거쳐 가져옵니다.
  - 같은 파일을 다시 올려도 겹치지 않습니다.
  - 가져올 때 자동으로 처리하는 것:
    - 아이디가 빈 기록은 닉네임으로 아이디를 찾아 채웁니다.
    - 날짜가 같은 회차가 있으면 그 회차에 연결합니다.
    - 상품 이름이 [상품 목록]과 같으면 그 상품에 연결합니다.
- **방송 회차 목록:** 참여 인원·별풍선 합 열을 추가했습니다.

## v1.2.0 (2026-09-30) — 채팅창 SOOP 방식, 수집 전용 창, 다크 디자인

**배포 파일:** PC 버전 `endgame-desktop-v1.2.0.zip` (새 폴더에 풀고 기존 `data` 폴더를 옮겨오기) / 웹 `endgame-web-v1.2.0.zip`

**웹 버전에 올릴 파일** (v1.1.0 에서 업데이트하는 경우):
- `activity.php`, `broadcast.php`, `chats.php`, `collector.php`, `donations.php`, `viewer.php`
- `api/status.php` (새 파일)
- `app/bootstrap.php`, `app/helpers.php`, `app/layout.php`
- `assets/app.css`, `assets/app.js`, `assets/collector.js`, `assets/soop-chat.js`
- `assets/fonts/` 폴더 (새 폴더: 글꼴 파일·라이선스)

**DB 변경:** 없음

**변경 내용:**
- **실시간 채팅창:**
  - SOOP 채팅창과 같이 오래된 채팅이 위, 새 채팅이 아래로 이어집니다.
  - 위로 올려 읽는 동안에는 자동으로 내려가지 않고 [새 채팅 N개 ↓] 버튼이 뜹니다.
  - 별풍선·애드벌룬·구독 알림도 채팅 흐름 안에 표시합니다. 오른쪽 후원 목록은 그대로 둡니다.
- **등급 배지·색:** 기존 끝장전 관제 화면과 같게 맞췄습니다.
  - 배지: 구독 '구'(파랑), 열혈 '열'(빨강), 팬 'F'(초록)
  - 닉네임 색: 열혈 빨강 > 구독 파랑 > 팬 초록
  - 방송인 'BJ', 매니저 '매' 배지를 추가했습니다.
  - 채팅 검색·순위·시청자 상세에도 같은 색을 씁니다.
- **구독자 판정 수정:** 구독 개월 필드로 판정합니다. 기존 시스템이 SOOP 화면과 대조해 확정한 방식입니다.
- **다른 방송국 선물 제외:** 다른 방송국으로 간 선물은 집계에서 뺍니다.
- **수집 전용 창:**
  - [실시간 수집] → [수집 창 열기]를 누르면 별도 창에서 수집하고, 메인 창에서는 다른 메뉴를 자유롭게 쓸 수 있습니다.
  - 모든 화면 위쪽에 [● 수집 중] 표시가 나오고, 누르면 수집 창으로 이동합니다.
- **채팅창 설정:** 글자 크기 50~200%, 채팅창 높이 조절(모서리 끌기), 시각 표시 켜기·끄기. 설정값은 기억합니다.
- **채팅 검색:** 기본을 시간순으로 바꾸고 [최신순] 전환과 [마지막 페이지] 버튼을 넣었습니다.
- **디자인:** 기존 끝장전 사이트의 다크 디자인을 적용했습니다.
  - 순위 1~3위에 메달, 순위표에 활약 막대를 표시합니다.
  - Pretendard 글꼴을 프로그램에 포함했습니다.

## v1.1.0 (2026-09-30) — PC 버전 추가

**배포 파일:**
- PC 버전: `endgame-desktop-v1.1.0.zip` (압축을 풀고 start-windows.bat 실행)
- 웹 업로드용: `endgame-web-v1.1.0.zip`

**웹 버전에 올릴 파일** (v1.0.0 에서 업데이트하는 경우):
- `app/bootstrap.php`, `app/config.sample.php`, `app/db.php`, `app/helpers.php`, `app/ingest.php`
- `app/layout.php`, `app/migrate.php`, `app/soop.php`, `app/stats.php`
- `excluded.php`, `export.php`, `import.php`, `login.php`, `viewer.php`
- (`install.php` 도 바뀌었지만, 이미 설치를 마쳤다면 올리지 않습니다)

**DB 변경:** 없음

**변경 내용:**
- **PC 버전 추가:**
  - 호스팅 없이 내 PC에서 실행합니다. 자료는 SQLite 파일 하나(`data` 폴더)에 저장합니다.
  - Windows는 처음 실행할 때 PHP를 자동으로 설치하고, 프로그램 창(크롬·엣지 앱 모드)으로 엽니다.
- **DB 호환:** 같은 코드가 MySQL과 SQLite 양쪽에서 동작하도록 SQL 문법을 정리했습니다.
- **백업 업로드:** 다른 PC·회차에서 수집한 백업 파일도 합칠 수 있게 했습니다. [다른 PC·회차의 백업 파일도 이 회차로 올리기]를 체크합니다.
- **첫 관리자 만들기:** 관리자 계정이 없으면 로그인 화면 대신 첫 관리자 만들기 화면으로 이동합니다.
- **Windows 인증서:** SOOP 조회 시 Windows 인증서 저장소도 함께 사용합니다.
