# Cafe24 가상서버 설치·운영 안내

운영 방식
- 프로그램은 **서버 한 곳**(Cafe24 가상서버)에서만 돌아갑니다. GitHub·다른 PC 를 거치지 않습니다.
- 화면은 PHP 템플릿 하나에 DB 데이터를 불러와 그립니다. 페이지를 미리 만들어 두는(생성) 방식이 아닙니다.
- 업데이트: Claude 가 알려 준 **바뀐 파일만** 파일질라(FTP/SFTP)로 덮어쓰기 → SSH 에서 `php app/check.php` 로 확인.
- DB 구조 변경은 파일을 올린 뒤 **첫 접속(또는 check.php 실행) 때 자동** 적용됩니다.

아래에서 `/var/www/endgame` 은 프로그램 폴더(= 저장소의 `www` 폴더 내용), `endgame.example.com` 은 실제 도메인으로 바꿔 읽습니다.

## 1. 서버 확인 (SSH 접속 후)

```bash
cat /etc/os-release | head -3     # OS 종류 (Ubuntu / Rocky·AlmaLinux·CentOS)

```

## 2. 설치 (새 서버)

### Ubuntu 22.04 / 24.04
```bash
sudo apt update
sudo apt install -y apache2 mariadb-server php php-mysql php-mbstring php-curl php-xml php-gd php-zip libapache2-mod-php unzip
sudo a2enmod rewrite headers
sudo systemctl enable --now apache2 mariadb
```
웹서버 계정: `www-data`

### Rocky / AlmaLinux 8·9
```bash
sudo dnf install -y epel-release
sudo dnf module reset -y php && sudo dnf module enable -y php:8.2
sudo dnf install -y httpd mariadb-server php php-mysqlnd php-mbstring php-curl php-xml php-gd php-zip unzip
sudo systemctl enable --now httpd mariadb php-fpm
sudo firewall-cmd --permanent --add-service=http --add-service=https && sudo firewall-cmd --reload
```
웹서버 계정: `apache` (아래 명령의 `www-data` 를 `apache` 로 바꿔 씁니다)

### DB 만들기 (공통)
```bash
sudo mysql_secure_installation          # root 비밀번호 설정, 나머지는 Enter(Y)
sudo mysql -e "CREATE DATABASE endgame CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'endgame'@'localhost' IDENTIFIED BY '여기에_긴_비밀번호';
GRANT ALL PRIVILEGES ON endgame.* TO 'endgame'@'localhost'; FLUSH PRIVILEGES;"
```

### PHP 업로드 한도 (백업 파일·상품 사진)
```bash
# Ubuntu: /etc/php/8.*/apache2/php.ini   Rocky: /etc/php.ini
sudo sed -i 's/^upload_max_filesize.*/upload_max_filesize = 200M/; s/^post_max_size.*/post_max_size = 210M/; s/^memory_limit.*/memory_limit = 512M/; s#^;*date.timezone.*#date.timezone = Asia/Seoul#' /etc/php/*/apache2/php.ini 2>/dev/null || sudo sed -i 's/^upload_max_filesize.*/upload_max_filesize = 200M/; s/^post_max_size.*/post_max_size = 210M/; s/^memory_limit.*/memory_limit = 512M/; s#^;*date.timezone.*#date.timezone = Asia/Seoul#' /etc/php.ini
```

### 웹사이트 설정 (Apache)
`/etc/apache2/sites-available/endgame.conf` (Rocky: `/etc/httpd/conf.d/endgame.conf`)
```apache
<VirtualHost *:80>
    ServerName endgame.example.com
    DocumentRoot /var/www/endgame
    <Directory /var/www/endgame>
        AllowOverride All
        Require all granted
    </Directory>
    # 내부 파일(설정·저장 폴더)은 주소로 열 수 없게
    <Directory /var/www/endgame/app>
        Require all denied
    </Directory>
</VirtualHost>
```
```bash
sudo mkdir -p /var/www/endgame
sudo a2ensite endgame && sudo a2dissite 000-default && sudo systemctl reload apache2   # Ubuntu
# sudo systemctl reload httpd                                                         # Rocky
```

### HTTPS (필수 — 로그인·개인정보·SOOP 채팅 연결에 필요)

## 3. 처음 올리기

1. 받은 `endgame-web-v버전.zip` 을 풀어 **안의 파일 전체**를 파일질라로 `/var/www/endgame` 에 올립니다.
   - 파일질라: [전송] → [전송 유형] → **바이너리** 권장
2. 권한:
   ```bash
   sudo chown -R www-data:www-data /var/www/endgame
   sudo find /var/www/endgame -type d -exec chmod 755 {} \; && sudo find /var/www/endgame -type f -exec chmod 644 {} \;
   ```
   FTP 계정으로 덮어쓰기가 안 되면 FTP 계정을 `www-data` 그룹에 넣고 `chmod -R g+w /var/www/endgame` 합니다.
3. 설정 파일 만들기 (SSH):
   ```bash
   cd /var/www/endgame
   sudo cp app/config.sample.php app/config.php
   php -r 'echo base64_encode(random_bytes(32)), PHP_EOL;'   # 나온 값을 복사
   sudo nano app/config.php     # DB 이름 endgame / 아이디 endgame / 비밀번호, app_key 에 위 값 붙여넣기 → Ctrl+O, Enter, Ctrl+X
   sudo chown www-data:www-data app/config.php && sudo chmod 640 app/config.php
   ```
   그다음 브라우저로 `https://endgame.example.com/` 접속 → 첫 관리자 계정을 만듭니다.
4. 확인: `cd /var/www/endgame && sudo -u www-data php app/check.php` → **결과: 오류 없음**

## 4. 업데이트 (매번)

1. Claude 가 알려 준 **바뀐 파일 목록**대로 파일질라로 덮어씁니다. (`docs/변경이력.md` 에도 버전별로 적혀 있습니다)
   - **절대 덮어쓰지 않는 것:** `app/config.php`, `app/storage/` 폴더
   - `app/manifest.json` 은 매번 함께 올립니다. (점검 도구가 파일 대조에 씀)
2. SSH:
   ```bash
   cd /var/www/endgame && sudo -u www-data php app/check.php
   ```
   - `[오류] 없음: …` → 그 파일을 안 올렸습니다.
   - `[주의] 내용 다름: …` → 옛 파일이 남아 있거나, 서버에서 직접 고친 파일입니다.
   - `[오류] … 문법` → 올리다 잘린 파일입니다. 다시 올립니다.
3. 브라우저에서 화면 아래 버전 번호가 새 버전인지 확인합니다.

**서버에서 직접 파일을 고친 경우** 그 파일을 Claude 에게 보내 주세요. Claude 가 가진 기본 소스와 맞춰 두어야 다음 수정 때 덮어써서 사라지지 않습니다.

## 5. 백업 (권장: 매일 새벽 자동)

```bash
sudo mkdir -p /var/backups/endgame
sudo crontab -e
# 아래 한 줄 추가: 매일 05:10 DB + 상품 사진·설정 백업, 14일 보관
10 5 * * * mysqldump --single-transaction endgame | gzip > /var/backups/endgame/db-$(date +\%F).sql.gz && tar czf /var/backups/endgame/files-$(date +\%F).tgz -C /var/www/endgame app/config.php app/storage/uploads && find /var/backups/endgame -mtime +14 -delete
```
`app/config.php` 의 `app_key` 를 잃으면 암호화된 수령자 정보를 영영 못 읽습니다. 백업 폴더도 따로 내려받아 두세요.
