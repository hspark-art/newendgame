# 끝장전 CG Windows 시험판

`Endgame-CG-v0.1.0-Windows-x64.zip` 파일을 열고 GitHub 파일 화면의 **Download raw file** 버튼으로 다운로드하세요. 비공개 저장소라면 접근 권한이 있는 계정으로 로그인해야 합니다.

1. ZIP 전체 압축을 해제합니다.
2. `Start-CG.bat`을 더블클릭합니다.
3. 첫 실행에는 인터넷 연결이 필요하며 공식 PHP를 자동 다운로드합니다.

현재는 샘플 데이터로 작동하는 초안입니다. 실제 Google Sheets 및 eloboard 데이터는 연결되지 않았습니다. ZIP 무결성과 압축 해제 후 기본 HTTP 기능은 클라우드에서 확인했으며, Windows 실행과 OBS/vMix 실송출은 미검증입니다.

세부 안내는 ZIP 내부의 `WINDOWS-사용안내.txt`를 참고하세요.
