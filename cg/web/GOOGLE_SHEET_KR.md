# Google 시트 연결 안내 (PC·웹 공통)

끝장전 데이터는 Google 시트에서 **읽기만** 합니다. 시트를 공개하지 않고, 이 프로그램 전용 "서비스 계정"에만 보기 권한을 줍니다.

## 읽는 범위
프로그램은 아래 탭과 열만 읽습니다. 상금 열과 다른 탭은 읽지 않고, 시트에는 아무것도 쓰지 않습니다.

| 탭 | 열 | 쓰는 곳 |
|---|---|---|
| Results | A~F (Winner, Race, Loser, Race, Map, Date) | 모든 CG 수치의 원본 (1행 = 1세트) |
| Players | A~O | 세트 전적 교차 검증 |
| 상대전적조회NEW | A~I | 끝장전 목록 교차 검증 |
| 중계진 예측 현황입력용 | A~Q | 승자 예측 기록·순위표 검증 |

탭 이름이 바뀌면 [데이터 점검·설정 → 데이터 설정]에서 바꿔 적습니다.

## 1. 서비스 계정 만들기 (처음 한 번)
1. https://console.cloud.google.com 에 접속해 새 프로젝트를 만듭니다(예: endgame-cg).
2. [API 및 서비스 → 라이브러리]에서 **Google Sheets API**를 찾아 "사용"을 누릅니다.
3. [API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정]으로 계정을 만듭니다.
   - 이름은 예를 들어 cg-reader로 합니다.
   - 역할은 주지 않고 건너뜁니다.
4. 만든 서비스 계정에서 [키 → 키 추가 → 새 키 만들기 → JSON]을 누릅니다. 키 파일이 내려받아집니다.

> **키 파일은 비밀번호와 같습니다.**
> - 메신저·메일·공유 드라이브에 올리지 마세요.
> - 프로그램에 등록한 뒤에는 내려받은 폴더에서 지우세요.
> - 키가 새어 나갔다고 생각되면 Google Cloud의 [키] 목록에서 바로 삭제하고 새로 만드세요.

## 2. 시트 공유
1. 끝장전 시트에서 [공유]를 누릅니다.
2. 서비스 계정 이메일(`…@….iam.gserviceaccount.com`)을 입력합니다.
3. 권한은 **뷰어**를 고르고 "알림 보내기"를 끈 뒤 공유합니다.
4. "링크가 있는 모든 사용자" 공개는 필요 없습니다. 켜지 마세요.

## 3. 프로그램에 등록
[데이터 점검·설정 → 데이터 설정]에서 진행합니다. 웹 버전은 관리자 계정만 할 수 있습니다.
1. 데이터 소스를 **Google 시트**로 고릅니다. 시트 주소는 주소창의 주소를 그대로 붙여 넣습니다. [설정 저장]을 누릅니다.
2. [키 파일(JSON) 등록]으로 1-4에서 받은 파일을 고릅니다. "등록된 키"에 서비스 계정 이메일이 나오면 됩니다.
3. [연결 테스트]를 누릅니다. 세트·끝장전 수와 불일치·이상 건수가 나오면 성공입니다.
4. 상단 [데이터 새로고침]을 누르면 CG에 반영됩니다. 자동 새로고침을 켜 두면 5분마다 다시 읽습니다.

키 파일 보관 위치:
- PC: `%LOCALAPPDATA%\EndgameCG\secrets\`
- 웹: `app/storage/secrets/`. Apache의 `.htaccess`로 막혀 있습니다.
  - 가능하면 `app/config.php`의 `secrets_dir`에 웹 폴더 밖 경로를 지정하세요.
  - **Apache가 아닌 서버(nginx 등)는 `.htaccess`가 동작하지 않습니다.** 반드시 웹 폴더 밖으로 지정하세요.
  - 키 폴더가 웹 폴더 안이면 데이터 설정 화면에 경고가 나옵니다.

## 4. 점검 화면 읽는 법
[데이터 점검·설정 → 점검] 탭에서 확인합니다.

- **대조됨 / 대조 불가**: 프로그램이 계산한 수치를 시트가 스스로 계산한 집계(Players 등)와 비교한 결과입니다.
- **시트 집계와 다른 항목**
  - 여기 나온 선수·항목을 쓰는 CG는 송출이 막힙니다.
  - 시트를 고치고 새로고침하거나, 확인한 값을 타이틀 에디터에 직접 입력하면 송출할 수 있습니다.
- **이상 경기**
  - 9세트가 아닌 끝장전, 동점, 경기 중 종족 변경 등이 해당합니다.
  - 세트 전적에는 들어가지만 끝장전 통계(맞대결·연승·풀세트·최근 전적)에서는 빠집니다. 해당 선수의 끝장전 CG는 확인 전까지 막힙니다.
- **끝장전 통계 제외 확정** (관리자)
  - 세트 수가 9가 아닌 특별 경기는 [끝장전 통계 제외 확정]을 누르면 끝장전 통계에서 빠집니다.
  - 확정한 경기의 관련 선수 CG는 막히지 않습니다. 세트 전적에는 그대로 들어갑니다.
  - 취소할 수 있습니다.
- **선수 정보**: 닉네임(soma, Light 등)은 시트에 없으므로 여기서 직접 입력합니다.

## 5. 연결이 안 될 때 (예비: 파일로 가져오기)
1. Google 시트에서 [파일 → 다운로드 → Microsoft Excel(.xlsx)]로 받습니다.
2. [데이터 설정 → xlsx 파일 가져오기]로 올립니다. 검증 방식은 같습니다.
3. 가져온 뒤에는 받은 파일을 지우세요. 시트 전체(상금 등)가 들어 있습니다.

| 메시지 | 확인할 것 |
|---|---|
| 시트에 접근할 권한이 없습니다 | 2단계 공유(뷰어)를 했는지, 이메일이 맞는지 |
| 서비스 계정 인증에 실패했습니다 | 키가 삭제·사용 중지되지 않았는지, PC 시계가 맞는지 |
| 시트를 찾을 수 없습니다 | 시트 주소 |
| 'Results' 탭이 없습니다 | 탭 이름 설정 |
| Results 탭 형식 오류 n건 | 안내된 행의 선수 이름·종족(P/T/Z)·날짜(2026-05-06 형식)를 고친 뒤 다시 새로고침 |
| openssl 확장이 없어 | PC: 새 버전의 PHP준비를 다시 실행. 그래도 안 되면 xlsx 가져오기를 쓰세요 |

오류가 나도 **마지막 정상 데이터와 송출 중인 CG는 그대로 유지**됩니다.
