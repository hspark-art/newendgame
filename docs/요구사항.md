# 요구사항 정의 (v1.0 기준)

작성일: 2026-09-30

## 1. 목적

SOOP(아프리카TV) 스타크래프트 끝장전 방송의 채팅·후원 내역을 확인하고, 이를 근거로 시청자 상품 지급을 관리한다.
예전 사이트를 대체하는 새 시스템이며, GitHub 자동 배포 없이 파일을 교체하는 방식으로 운영한다.

## 2. 결정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 | SOOP |
| 운영 방식 | PHP + MySQL 일반 웹호스팅, FTP로 파일 교체 (별도 웹 주소) |
| 호스팅 | 카페24 웹호스팅 권장 (대안: 가비아). PHP 8.1 이상, MariaDB, SSL |
| 채팅 수집 | 관리자 브라우저에서 실시간 수집 + 브라우저 백업 파일 업로드로 보완. PC 2대 동시 수집 지원(자동 중복 제거) |
| 연결 방식 | 비공식 방식(SOOP 웹 플레이어 통신 방식)으로 시작. 수집 부분만 교체할 수 있게 분리 |
| 후원 집계 | 별풍선(일반·중계방·영상풍선·도전/대결미션), 애드벌룬(일반·방송국), 구독(구독·연속 구독 알림·구독 선물) |
| 채팅 활동량 | 도배 제외 기준(연속 N초, 같은 내용 N초)과 활동 구간 수(N분 단위) 제공. 기준은 화면에서 조정 |
| 집계 제외 | 제외 명단 + 방송인·매니저 표시 아이디 자동 제외 |
| 동일인 판단 | 아이디 뒤 `(2)` 등 접속 번호는 떼고 합산 |
| 당첨자 정보 수집 | 관리자가 직접 입력 (쪽지 등으로 받은 정보) |
| 개인정보 | 암호화 저장, 목록 가림 표시, 지급 완료 후 30일 뒤 자동 파기, 열람 기록 |
| 권한 | 관리자(전체) / 담당자(개인정보 가림) |
| 중복 당첨 | 막지 않고 경고 표시 (같은 회차 기준) |

## 3. 이번 버전에서 제외 (추후 개발)

| 항목 | 비고 |
|---|---|
| 승부 예측 이벤트 | 채팅 명령어(`!예측 1` 등)로 참여, 세트별 접수·마감·정답 추첨 |
| 추첨 기능 | 조건에 맞는 시청자 중 무작위 추첨(가중 추첨 포함), 추첨 이력 기록 |
| 방송 화면 연동 | OBS 브라우저 소스로 순위·추첨 결과 표시 |
| 공식 채팅 SDK 전환 | SOOP 제휴 승인 후 수집 모듈 교체 |
| 당첨자 정보 입력 페이지 | 당첨 코드로 본인이 직접 입력하는 방식 |
| 비밀번호·19세·구독플러스 방송 | 로그인 연동 필요 |

## 4. 확인 필요 사항

1. **송출 채널:** 끝장전을 송출하는 곳이 자사 채널인지 외부 스트리머 채널인지 확인한다. 공식 SDK는 방송하는 계정 본인만 신청할 수 있다.
2. **예전 시스템:** 예전 시스템에서 불편했던 점과 꼭 필요한 기능을 확인한다.
3. **구독 집계 기준:** 실제 방송에서 아래 두 가지를 대조한다.
   - 구독 알림(신규·연속)이 화면 표시와 일치하는지
   - 랜덤 구독 선물이 받는 사람별로 들어오는지

## 5. 첫 방송 전 점검 (필수)

개발 환경에서는 SOOP 서버 접속이 막혀 있어, 가짜 채팅 서버로만 검증했다. 실제 운영 전에 아래를 확인한다.

1. **연결 확인:** 테스트용 회차를 만들고, 지금 방송 중인 아무 공개 방송의 방송국 ID로 [실시간 수집]을 시작한다.
   - 상태가 **수집 중**으로 바뀌고 채팅이 화면에 흐르는지 본다.
   - [저장 상태]의 **서버 저장** 숫자가 올라가는지 본다.
2. **후원 대조:** 별풍선·애드벌룬·구독이 들어오면 후원 목록에 표시되는지, 실제 방송 화면과 수량이 맞는지 대조한다.
3. **자동 재연결:** 수집 중에 인터넷을 잠깐 끊었다 연결했을 때 자동으로 다시 연결되는지 본다.
4. **백업 복구:** [백업 파일 내려받기] → [백업 업로드] 순서로 올렸을 때 "이미 있던 기록 N건 건너뜀"이 나오는지 본다.

연결이 안 되면 수집 화면의 **연결 기록** 내용을 캡처해 전달한다.
