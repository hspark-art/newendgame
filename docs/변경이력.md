# 변경 이력

업데이트할 때는 해당 버전의 **올릴 파일**만 FTP로 덮어쓰면 됩니다. (`app/config.php` 는 절대 덮어쓰지 않습니다)
경로는 `www` 폴더 기준입니다.

---

## v1.0.0 (2026-09-30) — 최초 버전

**올릴 파일:** `www` 폴더 전체 (최초 설치)

**DB 변경:** 최초 생성 (설치 후 첫 접속 때 자동)

**기능:**
- 방송 회차 관리
- SOOP 실시간 채팅·후원 수집
  - 브라우저 백업, 자동 재연결, 방송 재시작 대기
  - PC 여러 대 동시 수집과 자동 중복 제거
- 채팅 검색
- 후원 순위·후원 기록
- 채팅 활동량 (도배 제외, 활동 구간)
- 시청자 상세
- 백업 파일·CSV 업로드
- 상품 지급 관리
  - 순위에서 일괄 당첨 등록
  - 수령자 정보 암호화, 자동 파기
- 집계 제외 명단
- 관리자 계정·권한, 작업 기록
- CSV 내려받기 (엑셀 호환)
