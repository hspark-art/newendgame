끝장전 CG — PC 응용프로그램
스타크래프트 끝장전 방송 하단 데이터 CG 제작·송출 (Windows 10/11 64비트)

※ 처음에는 MOCK(검증용 가짜 수치)로 시작합니다. 실제 끝장전 데이터는 GOOGLE_SHEET_KR.md를 따라
  Google 시트를 연결하세요. [데이터 점검·설정] 버튼에서 연결·점검·선수 닉네임을 관리합니다.

■ 처음 한 번만
1. 이 폴더를 OneDrive 밖, 영문 경로에 둡니다. 예) C:\EndgameCG
2. "PHP준비.bat" 을 더블클릭합니다. 인터넷에서 PHP를 내려받아 runtime\php 에 넣습니다.
   자동으로 안 되면 화면 안내대로 직접 넣습니다:
   https://windows.php.net/download → PHP 8.3 "VS16 x64 Non Thread Safe" Zip
   → 받은 파일 마우스 오른쪽 > 속성 > "차단 해제" → 압축을 풀어 php.exe 가 runtime\php 안에 오게 합니다.
3. PHP가 실행되지 않는다는 안내가 나오면 Microsoft Visual C++ 재배포 패키지(x64)를 설치합니다.
   https://aka.ms/vs/17/release/vc_redist.x64.exe

■ 실행
- "시작.bat" 더블클릭 → 조작 패널이 전용 창으로 열립니다.
  최소화된 "끝장전 CG 서버" 창이 프로그램 본체입니다. 이 창을 닫으면 송출이 멈춥니다.
- 다시 더블클릭하면 서버는 그대로 두고 조작 패널만 다시 엽니다.
- 끝낼 때: "종료.bat" (또는 서버 창 닫기)
- OBS/vMix가 다른 PC에 있으면 "시작-LAN.bat" 으로 실행합니다.
  처음에 Windows 방화벽 창이 뜨면 "개인 네트워크"를 허용하세요. 조작 패널은 이 PC에서만 열립니다.

■ OBS / vMix 연결
- 브라우저 소스(웹 브라우저 입력)에 아래 주소를 넣고 크기를 1920 × 1080 으로 맞춥니다.
    같은 PC:   http://127.0.0.1:3100/output.php?layer=1
    다른 PC:   조작 패널 오른쪽 "송출 주소"에 표시되는 주소 (시작-LAN.bat 실행 시)
- 배경은 투명입니다. CG가 없을 때는 아무것도 보이지 않습니다.
- 조작 패널의 "출력 연결" 표시에 초록불이 들어오면 연결된 것입니다.

■ 방송 중 사용 순서 (토네이도식)
1. [+ 페이지 추가] 로 이번 경기에 쓸 CG를 순서대로 등록합니다. (001, 002 … 페이지 번호)
   종류(CG 9종: 종족 승률·최근 전적·맞대결·다승·승자 예측·온라인·더블 찬스·연승·풀세트)를 고르면 필요한 입력칸만 나옵니다.
2. 숫자를 누르고 Enter → 그 페이지가 PREVIEW(녹색)에 준비됩니다. 행을 클릭해도 됩니다.
3. 타이틀 에디터에서 값을 확인합니다. 고칠 값은 MANUAL 칸에 입력 → Ctrl+S (SAVE TO PREVIEW)
4. F1 또는 Space = TAKE → PROGRAM(빨강)으로 송출되고 화면에 나타납니다.
5. F2 = OUT(내리기), F3 = SHOW(다시 띄우기), F4 또는 ↓ = 다음 페이지 준비, ↑ = 이전 페이지
6. 송출 중인 CG의 숫자를 급히 고칠 때: 같은 페이지를 PREVIEW에 둔 상태에서 값 입력 → [UPDATE LIVE]
   (변경 내용을 확인하는 창이 뜹니다. 다른 CG가 송출 중이면 적용되지 않습니다.)
- 입력칸에 커서가 있을 때는 단축키가 동작하지 않습니다.

■ 알아둘 점
- 자동값(AUTO)과 수정값(MANUAL)은 따로 저장됩니다. 데이터 새로고침은 수정값을 지우지 않습니다.
- 되돌리기 = 자동값으로 복귀 (PREVIEW만 바뀝니다. 송출값은 TAKE/UPDATE LIVE 해야 바뀝니다.)
- 새 세션 = 다음 방송 시작. 수정값은 모두 AUTO로 돌아가고 KEEP 체크한 값만 넘어갑니다.
- 작업 데이터 위치: %LOCALAPPDATA%\EndgameCG (cg.sqlite)
- Google 서비스 계정 키 위치: %LOCALAPPDATA%\EndgameCG\secrets (다른 사람에게 보내지 마세요)
  새 버전은 새 폴더에 풀어서 쓰면 됩니다. 페이지 리스트·수정값·송출 상태가 그대로 이어집니다.
- 페이지 리스트는 [내보내기] 파일로 다른 PC나 웹 버전에 [가져오기] 할 수 있습니다.

■ 문제 해결
- "서버가 시작되지 않았습니다": 다른 프로그램이 3100 포트를 쓰는지 확인하고, 최소화된 서버 창의 메시지를 봅니다.
- 조작 패널 상단 "서버 연결 끊김": 서버 창이 닫혔는지 확인 → 시작.bat 다시 실행.
  송출 화면은 마지막 화면을 유지한 채 자동으로 다시 연결됩니다.
- 데이터 상태가 "STALE" / "데이터 오류": 마지막 정상 데이터로 계속 송출할 수 있습니다. 원인을 확인한 뒤 데이터 새로고침(F5).
