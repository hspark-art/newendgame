끝장전 채팅·상품 관리 - PC 버전 사용 안내
====================================================

이 프로그램은 인터넷 서버 없이 내 PC 에서 바로 실행하는 버전입니다.
기능은 웹 버전과 같습니다. (채팅·후원 실시간 수집, 후원 순위, 채팅 활동량, 상품 지급 관리)


■ 실행 방법 (Windows)

  1. 압축 파일을 원하는 곳(예: 문서 폴더)에 풉니다.
     ※ 압축을 풀지 않은 상태로 실행하면 안 됩니다.
  2. start-windows.bat 을 더블클릭합니다.
     - 처음 한 번은 필요한 구성요소(PHP)를 자동으로 내려받습니다. (약 1~2분, 인터넷 필요)
     - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
     - Visual C++ 런타임 설치 창이 뜨면 [예]를 누릅니다.
  3. 프로그램 창이 열리면 첫 관리자 계정을 만들고 사용합니다.
  4. 까만 창(실행 창)은 사용하는 동안 켜두세요. 최소화는 괜찮습니다.
     까만 창을 닫으면 프로그램이 종료됩니다.

  * 크롬이나 엣지가 설치되어 있으면 주소창 없는 프로그램 창으로 열립니다.
  * 프로그램 창을 실수로 닫았으면 start-windows.bat 을 다시 누르면 됩니다.


■ 실행 방법 (Mac)

  1. 터미널에서 PHP 를 설치합니다. (처음 한 번, Homebrew 필요: https://brew.sh)
         brew install php
  2. start-mac.command 를 더블클릭합니다.
     - "확인되지 않은 개발자" 경고가 뜨면 파일을 우클릭 → [열기]로 실행합니다.


■ 방송 당일 사용 순서

  1. [방송 회차] → [+ 새 회차 등록]: 제목, SOOP 방송국 ID, 방송일 입력
  2. [실시간 수집] → [수집 창 열기] → 새로 뜬 수집 창에서 [수집 시작].
     방송 전에 켜두면 방송이 시작될 때 자동으로 연결됩니다.
     수집 창은 켜둔 채로, 메인 창에서 다른 메뉴를 자유롭게 사용하세요. (위쪽에 ● 수집 중 표시)
  3. [후원 순위] · [채팅 활동량]에서 확인 → 체크 후 [당첨 등록]
  4. [상품 지급]에서 수령자 정보 입력 → 지급 완료 처리

  * 수집하는 동안 PC 가 절전 모드로 들어가지 않게 해주세요. (노트북은 전원 연결)
  * PC 두 대로 동시에 수집해도 됩니다. (각 PC 에 따로 저장됨)
    끝난 뒤 보조 PC 의 [실시간 수집] → [백업 파일 내려받기] 파일을 메인 PC 의 [백업 업로드]에
    올리면 합쳐집니다. 양쪽에 모두 있는 기록은 한 번만 저장됩니다.


■ 자료 보관 · 백업

  - 모든 자료(채팅, 후원, 지급 기록, 설정)는 프로그램 폴더 안의 data 폴더에 저장됩니다.
  - 백업: 프로그램을 종료한 뒤 data 폴더를 통째로 복사해 두세요.
  - data/config.php 안의 app_key 는 수령자 개인정보를 푸는 열쇠입니다. 지우거나 바꾸지 마세요.
  - 이 PC 를 다른 사람과 함께 쓴다면 관리자 계정 비밀번호를 꼭 설정하고, 사용 후 로그아웃하세요.


■ 새 버전으로 바꿀 때

  1. 실행 중인 프로그램(까만 창)을 닫습니다.
  2. 새 버전 압축을 다른 폴더에 풉니다.
  3. 기존 폴더의 data 폴더를 새 폴더로 복사합니다. (php 폴더도 복사하면 다시 내려받지 않습니다)
  4. 새 폴더의 start-windows.bat 을 실행합니다. DB 변경이 있으면 자동으로 적용됩니다.


■ 문제 해결

  - "PHP 설치 실패": 인터넷 연결을 확인하고 다시 실행합니다.
    회사 보안 프로그램이 내려받기를 막는 경우 아래 "직접 설치하는 방법"을 따르세요.
  - "사용할 수 있는 포트가 없습니다": PC 를 다시 시작한 뒤 실행합니다.
  - 화면이 이상하면 프로그램 창에서 Ctrl+F5 (새로고침)
  - 그 밖의 오류: data/server.log 파일을 담당자에게 전달해 주세요.


■ 직접 설치하는 방법 (자동 설치가 안 될 때)

  1. https://windows.php.net/download/ 에서 "VS17 x64 Non Thread Safe" (또는 VS16) 의 Zip 을 받습니다. (PHP 8.3 이상)
  2. 프로그램 폴더 안에 php 폴더를 만들고, 받은 압축을 그 안에 풉니다. (php\php.exe 가 있어야 함)
  3. php 폴더 안에 php.ini 파일을 만들고 아래 내용을 넣습니다.
         extension=curl
         extension=fileinfo
         extension=mbstring
         extension=openssl
         extension=pdo_sqlite
         extension=sqlite3
         date.timezone = Asia/Seoul
         upload_max_filesize = 512M
         post_max_size = 520M
         memory_limit = 512M
  4. "VCRUNTIME140.dll 이 없습니다" 오류가 나면 아래를 설치합니다.
         https://aka.ms/vs/17/release/vc_redist.x64.exe
  5. start-windows.bat 을 다시 실행합니다.


■ 알아둘 점

  - SOOP 채팅은 SOOP 공식 API 가 아닌 방식으로 받습니다. SOOP 쪽 방식이 바뀌면 프로그램 수정이 필요합니다.
  - 비밀번호 방송, 19세 방송, 구독플러스 전용 방송은 아직 지원하지 않습니다.
  - 처음 쓰기 전에 지금 방송 중인 아무 공개 방송으로 수집이 되는지 한 번 확인해 주세요.
