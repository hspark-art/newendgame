# 끝장전 채팅·상품 관리

SOOP(아프리카TV) 스타크래프트 끝장전 방송의 **채팅·후원(별풍선·애드벌룬·구독)을 실시간으로 수집**하고,
**후원 순위·채팅 활동량**을 확인해 **상품 지급**까지 관리하는 웹 프로그램입니다.

- PHP + MySQL(MariaDB)로 만든 일반 웹호스팅용 프로그램입니다. 프레임워크나 추가 설치 프로그램이 없습니다.
- GitHub와 자동으로 연결되지 않습니다. 파일을 고친 뒤 **FTP로 직접 올리는 방식**으로 반영합니다.
- 같은 저장소의 `cg/` 폴더는 별개 프로그램인 **끝장전 CG**(방송 데이터 CG 제작·송출)입니다. 설명은 [cg/README.md](cg/README.md)를 보세요.

---

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 방송 회차 | 끝장전 1회 = 1건. SOOP 방송국 ID를 등록합니다. |
| 실시간 수집 | 관리자 PC 브라우저 창을 켜두면 채팅·후원을 받아 서버에 저장합니다. 같은 내용을 브라우저에도 백업합니다. |
| 채팅 검색 | 내용·시청자·시간대로 검색하고 CSV로 내려받습니다. |
| 후원 순위 | 별풍선·애드벌룬·구독·구독 선물을 시청자별로 합산한 순위입니다. 시간대와 최소 개수로 거를 수 있습니다. |
| 채팅 활동량 | 도배를 뺀 채팅 수와 활동 구간 수(꾸준히 참여했는지)로 순위를 냅니다. |
| 시청자 상세 | 한 시청자의 채팅·후원·당첨 기록을 모아 봅니다. |
| 백업 업로드 | 수집 화면의 백업 파일이나 외부 채팅 CSV를 올려 빠진 기록을 채웁니다. 중복은 자동으로 건너뜁니다. |
| 상품 지급 | 순위 화면에서 고른 시청자를 당첨 등록하고, 수령자 정보 입력 → 지급 완료까지 관리합니다. |
| 제외 명단 | 스태프·봇 등 집계에서 뺄 아이디입니다. 방송인·매니저는 자동으로 빠집니다. |
| 관리자 · 작업 기록 | 계정 관리와 로그인·개인정보 열람·지급 처리 기록입니다. |

## 폴더 구성

```
newendgame/
├─ www/                 ← 서버에 올리는 폴더 (이 안의 내용 전체)
│  ├─ *.php             화면
│  ├─ api/              수집 화면이 쓰는 서버 기능
│  ├─ assets/           화면 모양(css)·동작(js)
│  └─ app/              내부 기능 (브라우저에서 직접 열 수 없음)
│     ├─ config.sample.php   설정 견본 → config.php 로 복사해서 사용
│     └─ migrate.php         DB 구조 (자동 적용)
└─ docs/                ← 문서 (서버에 올리지 않음)
   ├─ 요구사항.md
   └─ 변경이력.md       버전별로 바뀐 파일 목록
```

## 최초 설치

### 1. 호스팅 준비

아래 조건을 갖춘 일반 웹호스팅이면 됩니다. (예: 카페24 웹호스팅, 가비아 웹호스팅)

- **PHP 8.1 이상** (가입할 때 PHP 버전을 8.x로 선택)
- **MySQL 또는 MariaDB**
- **SSL(https)** 적용 권장. 로그인 정보와 수령자 개인정보가 오가기 때문입니다. 대부분 무료 SSL을 제공합니다.
- **DB 용량:** 끝장전 1회에 채팅이 수십만 건 쌓일 수 있으므로 넉넉한 요금제를 고릅니다.
  끝난 회차는 [요약] 화면의 **채팅 데이터 정리**로 비울 수 있습니다. 비우기 전에 CSV로 받아두세요.

### 2. 설정 파일 만들기

1. `www/app/config.sample.php` 를 복사해서 같은 폴더에 `config.php` 로 저장합니다.
2. 호스팅 관리 화면에서 확인한 **DB 이름·아이디·비밀번호**를 `db` 항목에 입력합니다.
3. `app_key` 는 비워둔 채로 다음 단계로 넘어갑니다.

### 3. 파일 올리기 (FTP)

FTP 프로그램(파일질라 등)으로 `www` 폴더 **안의 내용 전체**를 호스팅의 웹 폴더에 올립니다.
카페24의 웹 폴더는 `www` 입니다.

### 4. 설치 화면

1. 브라우저에서 `https://내주소/install.php` 에 접속합니다.
2. 화면에 나오는 **암호화 키**를 복사해 `config.php` 의 `app_key` 에 붙여넣고, config.php 를 다시 올립니다.
   이 키는 수령자 개인정보를 암호화하는 데 씁니다. **한 번 정하면 절대 바꾸지 말고**, 따로 안전한 곳에 보관합니다.
3. 새로고침하면 나오는 화면에서 첫 관리자 계정을 만듭니다.
4. **서버에서 `install.php` 파일을 삭제**합니다.

## 업데이트 방법 (파일 교체)

1. `docs/변경이력.md` 에서 이번 버전에 **바뀐 파일 목록**을 확인합니다.
2. 해당 파일만 FTP로 덮어씁니다. 헷갈리면 `www` 전체를 올려도 됩니다. 단, 아래 두 가지는 지킵니다.
   - `app/config.php` 는 **절대 덮어쓰지 않습니다.** 저장소에는 없는 파일이라 보통은 문제가 생기지 않습니다.
   - `install.php` 는 다시 올리지 않습니다.
3. DB 구조가 바뀐 버전이라면, 올린 뒤 **처음 접속할 때 자동으로 적용**됩니다. 따로 할 일은 없습니다.
4. 화면 맨 아래의 **버전 번호**가 바뀌었는지 보고 반영됐는지 확인합니다.
   화면이 예전 모양이면 브라우저에서 새로고침(Ctrl+F5)합니다.

## 방송 당일 사용 순서

1. **[방송 회차] → [+ 새 회차 등록]**: 제목, SOOP 방송국 ID, 방송일을 입력합니다.
2. **[실시간 수집]**: 방송 시작 전에 **[수집 시작]** 을 누르고 창을 켜둡니다.
   - 방송이 아직 안 켜졌으면 **자동으로 기다렸다가** 연결합니다. 방송이 중간에 꺼졌다 켜져도 다시 연결합니다.
   - 안정성을 위해 **PC 두 대에서 동시에 수집**하는 것을 권장합니다. 겹치는 기록은 한 번만 저장됩니다.
   - 노트북은 전원을 연결하고 절전 모드를 끕니다.
3. **확인**: 방송 중이나 방송 후에 **[후원 순위]**, **[채팅 활동량]** 에서 확인합니다. 시간 범위를 정해서 특정 경기 구간만 볼 수도 있습니다.
4. **당첨 등록**: 순위 표에서 시청자를 체크하고, 아래 **[선택한 시청자 당첨 등록]** 에 상품명을 입력합니다.
5. **지급 관리**: **[상품 지급]** 에서 수령자 정보를 입력하고 상태를 **정보 대기 → 정보 받음 → 지급 완료** 로 바꿉니다.
6. **수집이 끊겼을 때**: 수집 화면의 **[백업 파일 내려받기]** 로 받은 파일을 **[백업 업로드]** 에 올리면 빠진 부분이 채워집니다.

## 권한

| 권한 | 할 수 있는 일 |
|---|---|
| 관리자(admin) | 모든 기능, 계정 관리, 작업 기록, 수령자 개인정보 전체 보기·내보내기 |
| 담당자(staff) | 조회·수집·당첨 등록·지급 처리. 수령자 개인정보는 가려서 보이고, 새로 입력하는 것만 가능 |

## 개인정보 처리

- **암호화 저장:** 수령자 이름·연락처·주소는 암호화해서 저장합니다. 목록에서는 가려서 보여줍니다.
- **자동 파기:** 지급 완료(또는 기한 초과) 후 `privacy_retention_days`(기본 30일)가 지나면 자동으로 파기합니다.
- **작업 기록:** 개인정보 열람, 내려받기, 지급 처리, 로그인 기록을 [작업 기록]에 남깁니다.
- **동의 문구:** 수령자 정보를 받을 때의 수집·이용 동의 문구는 쪽지나 공지로 따로 안내해야 합니다.

## 알아둘 점

- **SOOP 채팅 연결 방식:** SOOP 공식 API가 아니라, SOOP 웹 플레이어가 쓰는 채팅 통신 방식을 따라 만들었습니다.
  - SOOP 쪽 방식이 바뀌면 `www/assets/soop-chat.js` 와 `www/app/soop.php` 를 수정해야 합니다.
  - 공식 채팅 SDK는 제휴 승인(최대 10영업일)이 필요하고, 키를 받은 계정의 본인 방송에서만 쓸 수 있습니다.
- **첫 사용 전 점검 필요:** 개발 환경에서는 SOOP 서버 접속이 막혀 있어서, 실제 SOOP 방송 연결은 **테스트 방송으로 확인이 필요합니다**. 확인 방법은 `docs/요구사항.md` 의 "첫 방송 전 점검"을 참고합니다.
- **지원하지 않는 방송:** 비밀번호 방송, 19세 방송, 구독플러스 전용 방송은 아직 지원하지 않습니다.
- **집계 기준:**
  - 별풍선 합계에는 일반·중계방·영상풍선·도전미션·대결미션이 모두 포함됩니다.
  - 구독은 구독·연속 구독 알림 건수, 구독 선물은 선물 받은 사람 수입니다.
  - 아이디 뒤에 `(2)` 처럼 번호가 붙은 기록은 같은 계정으로 보고 합산합니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 설치 화면에서 DB 접속 실패 | config.php 의 DB 이름·아이디·비밀번호, 호스트(`localhost`) |
| 모든 화면이 흰 화면 / 500 오류 | 호스팅 PHP 버전이 8.1 이상인지 확인합니다. config.php 의 `debug` 를 잠깐 `true` 로 바꾸면 오류 내용이 보입니다. |
| 자주 로그아웃됨 | config.php 의 `session_path` 에 웹 폴더 밖의 쓰기 가능한 폴더를 지정합니다. |
| 백업 파일 업로드 실패 (용량) | 압축 백업(.gz)을 씁니다. 그래도 안 되면 호스팅 설정에서 업로드 한도를 늘립니다. |
| 수집 화면 "방송 정보를 가져오지 못했습니다" | 방송국 ID를 확인합니다. SOOP 쪽 방식이 바뀌었을 수 있습니다. |

## 개발 메모 (수정하는 사람용)

- **DB 구조 변경:** `www/app/migrate.php` 의 `migrations()` 맨 끝에 새 번호로 추가합니다. 이미 적용된 번호의 내용은 절대 고치지 않습니다.
- **버전 올리기:** `www/app/bootstrap.php` 의 `APP_VERSION` 을 올리고, `docs/변경이력.md` 에 바뀐 파일을 적습니다.
  CSS·JS 주소에 버전이 붙어 있어서 버전을 올려야 브라우저가 새 파일을 받습니다.
- **로컬 실행:** `php -S 127.0.0.1:8000 -t www` 로 실행합니다. MariaDB와 `app/config.php` 가 필요합니다.
